# Comfort Sense artwork

The original transparent logomark was created with the built-in image generation
tool. Production exports only resize that artwork; no redraw or recoloring was
applied. The original generated file remains preserved in the local image archive.

- `logo.png`: 512 × 512, documentation logo.
- `../../custom_components/comfort_sense/brand/icon.png`: 256 × 256, HA icon.
- `../../custom_components/comfort_sense/brand/icon@2x.png`: 512 × 512, HA retina icon.

The square mark serves as the logo and icon, so the HA brand directory needs only
icon files. Local integration brand images follow the [official HA guide](https://developers.home-assistant.io/docs/core/integration/brand_images/).

## Generation prompt

Use case: logo-brand. Asset: a polished square logomark for the open-source Home Assistant custom integration named Comfort Sense Thermostat. Create a distinctive, minimal, flat geometric emblem: a soft rounded house outline wrapped around a thermostat dial; the dial has one warm orange rising crescent and a small warm dot, suggesting comfortable heating and morning readiness. Confident deep teal outline, warm orange accent; only these two solid colors. Clean generous negative space, balanced optical weight, friendly modern identity, thick rounded geometry readable at 48 pixels. Center the emblem with about 12 percent transparent margin on each side. Actual transparent background. No text, no letters, no wordmark, no mockup, no shadows, no textures, no gradients, no watermark, no Home Assistant logo or trademarked imagery. One finished logo, not a sheet of variations. Square high-resolution PNG.
