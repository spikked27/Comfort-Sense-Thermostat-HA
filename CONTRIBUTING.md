# Contributing

Keep control and learning deterministic and separate from HA I/O. Add regression
tests for control failures, unit errors, sensor outages and learning rejection.
Document changes to time units, gain units, configuration compatibility and relay
behavior. Preserve manual gains and per-controller automatic-tuning choices.

Do not attach tokens, complete HA configuration files, occupancy histories, room
entity IDs, or unredacted household datasets to issues. Reproduce with synthetic
data whenever possible. Follow [verification](docs/TESTING.md) before proposing a
release. All contributions are under the MIT license.
